# Video topics door

Personal-use GitHub Pages door for the short-video topic tracker.

- This repository does **not** contain the topic list or any scripts.
- The page is password-gated (AES-GCM). After unlock it only reveals a private
  path to the live tracker on the home Tailscale network.
- Viewing the live list still requires Tailscale and the machine that hosts it.
- The password is stored only on the host machine, not in this repo.

Pages URL: https://algowise-ai.github.io/video-topics/
